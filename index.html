Cài đặt kết nối Google Sheets

Làm theo các bước sau để kết nối ứng dụng với Google Sheets của bạn.

Bạn cần tạo Google Apps Script và triển khai nó dưới dạng Web App. Xem hướng dẫn bên dưới.

Hướng dẫn cài đặt

  1. Mở sheets.new để tạo Google Sheet mới. Copy Sheet ID từ URL (phần giữa /d/ và /edit).
  2. Mở script.google.com → Tạo project mới → Dán nội dung file Code.gs vào.
  3. Thay SHEET_ID = '' bằng ID sheet của bạn ở bước 1.
  4. Chạy hàm setupSheets() một lần để tạo các sheet và dữ liệu mẫu.
  5. Vào Deploy → New deployment → Chọn Web app → Execute as: Me → Access: Anyone → Deploy.
  6. Copy URL Web App và dán vào ô bên dưới.
